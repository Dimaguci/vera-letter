# Вера, это всё для тебя ♡

Персональное любовное приключение от Димы для Веры. Статический сайт без зависимостей и платных сервисов. Все изображения, звуки и взаимодействия работают локально; музыка создаётся браузером после включения звука.

## Посмотреть на компьютере

В родительской папке находится **`Для Веры.html`** — самостоятельная копия всего сайта. Открывается двойным щелчком, даже без интернета. После изменения исходников обновить её командой `npm run preview:file`.

Из папки проекта запустить:

```powershell
npm run dev
```

Открыть http://127.0.0.1:4173. Для остановки нажать Ctrl+C в терминале.

## История

Приветствие → маленькое признание → убегающая кнопка «Нет» → шесть ключей → конверт → письмо → сертификат на желание → приглашение в другую комнату.

Шесть ключей:

1. Дата свадьбы: **31 октября 2020 года**. Поддерживаются разные записи даты, в том числе словами. Подсказки постепенно доходят до ответа.
2. Знакомство: **лагерь «Чайка», летняя школа, 2016 год**.
3. Первый поцелуй: **12 августа, у конгазской церкви**.
4. Любимое меню Димы: **жареные яйца и пельмени**.
5. Семейная шутка про соску: **«В смысле где? Ты же тут»**.
6. Мини-игра: найти пары имён **Дима, Вера, Сашка, Евочка**.

Ошибки не отнимают попытки. Игру можно пройти с помощью подсказок. Кнопка «Нет» убегает пять раз и затем разрешает нажать себя. На телефоне реагирует на касание, на компьютере — на наведение, с клавиатуры — на нажатие.

Прогресс сохраняется в текущем браузере. Круглая кнопка со стрелкой вверху позволяет начать заново. Перед передачей того же устройства Вере можно сбросить свой тестовый прогресс. На её устройстве игра начнётся с начала.

## Редактирование

- `app.js` — все тексты, сюжет и письмо (`letterParagraphs`).
- `styles.css` — оформление и анимации, включая мобильную версию и уменьшение движения по настройке устройства.
- `game-logic.js` — проверка ответов и сохранения.
- `assets/vera-sticker.png` — исходный стикер, присланный Димой.

## Публикация на GitHub Pages

Содержимое этой папки готово к статической публикации: загрузить в корень выбранного репозитория и включить Pages из ветки с каталогом `/ (root)`. Файл `.nojekyll` уже добавлен. Сборка не нужна.

Никакие ответы или желания не отправляются на сервер. Дата в квесте — игровая загадка; исходники статического сайта содержат ответы и письмо.
